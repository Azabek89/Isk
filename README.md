# Генератор искового заявления (РК)

Статический сайт для подготовки искового заявления в суды гражданской юрисдикции Республики Казахстан.
Истец: АО «Казахтелеком». Ввод: ФИО ответчика, сумма иска, суд, лицевой счёт, период пользования услугами связи.

- Основа: ГПК РК (ст. 148–149), Налоговый кодекс РК (ст. 610, госпошлина).
- Работает полностью в браузере, данные никуда не отправляются.
- Реквизиты истца сохраняются только в браузере пользователя (localStorage).

**Документ — черновик.** Перед подачей в суд проверьте факты, расчёт госпошлины, подсудность и приложения.

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: Deploy from a branch; Branch: `main`, папка `/ (root)`.
3. Сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
